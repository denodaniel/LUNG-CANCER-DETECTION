# LUNG-CANCER-DETECTION
# 🧬 Lung Cancer Genomic AI Pipeline
### Autoencoder + Latent Space Classification + Explainable AI

An advanced deep learning pipeline for **lung cancer genomic analysis**, designed to identify cancer patterns, classify disease status, and discover potential biomarkers using **Autoencoders, Latent Feature Classification, and Explainable AI**.

---

## 📌 Overview

This project applies **Artificial Intelligence in Precision Medicine** by leveraging high-dimensional genomic data to:

- Detect lung cancer patterns
- Learn compressed biological representations
- Predict cancer vs normal samples
- Identify top influential genes
- Support biomarker discovery and therapeutic research

---

## 🚀 Key Features

- **Deep Autoencoder** for genomic feature compression
- **Latent Space Visualization** using PCA
- **Supervised Neural Classifier**
- **Explainable AI for Biomarker Ranking**
- **Confusion Matrix & ROC-AUC Evaluation**
- **Top 50 Gene Extraction**
- Fully reproducible pipeline
